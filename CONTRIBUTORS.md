## How to contribute

Flatrun is a proprietary product and we are not currently accepting external
contributions. If you have an idea, bug report, or security concern, please
use the channels listed in [SECURITY.md](./SECURITY.md) or reach out to the
maintainers directly.

## Adding yourself to this list

If you join the project as a maintainer or contributor with write access, add
yourself to the appropriate section above in your first PR. Use the format:

```
### Your Name (Role)
- **Role:** brief description of your role
- **GitHub:** [@your-handle](https://github.com/your-handle)
- **Responsibilities:** what you own
```
